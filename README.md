# Lardelli - Portada de Diario Digital

Proyecto academico de una portada de diario digital sobre Rosario, con identidad propia, estructura semantica en HTML5 y diseno responsivo con CSS Grid.

## Descripcion breve

Trabajo practico enfocado en Mobile First, con portada principal, noticias por secciones, publicidades integradas y navegacion adaptable para celular, tablet y escritorio.

## Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid
- Media Queries

## Estructura del proyecto

- `index.html`
- `reset.css`
- `style.css`
- `responsive.css`
